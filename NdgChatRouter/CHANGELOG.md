# Changelog

## 0.0.1

- First version. Selected system messages are also shown in the chat tabs you choose:
  - PvP kill feed, friend online/offline, guild keep attack updates, group join/leave.
  - Configured per tab name in the settings panel; tabs that already show System messages are skipped, so nothing appears twice.
  - Messages keep the chat's formatting, including pChat's if it is active.
- `/ndgchat` lists which message groups go to which tab.
