# Changelog

## 0.1.0

- First version. The Add-Ons screen shows "Used by x/y" or "Unused" on libraries.
  - Hover the text for the list of users; click it or expand the row to see them in the row.
  - Unneeded libraries are followed through the dependency chain.
- `/ndglibusage` lists libraries without an active user; `/ndglibusage <name>` shows the users of one addon.
